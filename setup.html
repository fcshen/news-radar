怎么拿到这些地址

    
    
      
  1. Bark（主通道）：iPhone 在 App Store 搜 Bark，免费，装上打开。首页会显示一条 https://api.day.app/xxxxx 的地址，点一下复制，粘到上面。
    2. 
      
  2. 企业微信（备用）：手机企业微信里建一个只有自己的群 → 右上角 … → 群机器人 → 添加 → 复制它给的 Webhook 地址，粘到上面。
    3. 
      
  3. ntfy（备用）：装 ntfy App，在 App 里订阅一个频道名（自己起，别人猜不到就行），把同一个名字填到上面。
    4. 
      
  4. 填完点保存，再点「发一条测试」，手机响了就成了。
    5. 
    

    

      这三个通道之间是串联：先试 Bark，3 秒内没成功就换企业微信，再不行换 ntfy。
      任何一条送到就算送达，不会重复轰炸。

      某条通道刚失败过会歇 90 秒，之后的消息直接走能用的那条，不浪费时间在坏通道上。

      这些地址等于你的通知钥匙，别发给别人。它们只存在这台电脑上（云端则存在仓库 Secrets 里）。
