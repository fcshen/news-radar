读完文档后，请先回我一句「已读完」，并列出你认为当前最需要关注的 3 件事，然后等我说要做什么。

几条**不要重新讨论**的既定结论（都是实测得来的，文档里有依据）：

- 不要建议注册 cron-job.org 或任何外部定时器。已试过，我这边网络注册不上；现在用工作流「续链」+ `*/20` cron + watchdog 三层保活，够用。
- 不要把 `raw.githubusercontent.com` 当主数据通道。它的 CDN 锁 300 秒，实测恒旧 5 分钟。主通道是 Pages 带秒级参数。
- 改前端**必须**把 `sw.js` 的 `SHELL` 版本号 +1，否则手机吃旧页面。
- 推送 `data/` 只用 `tools/push_data.sh`，不要用裸 `git pull` / `git push`，历史上因此停摆过一次。
- 抓取间隔不要压到 20 秒以下，33 个免费源会被限流。

我的环境：Windows，Git Bash，改代码需要开 VPN（代理 `http://127.0.0.1:7897`）。我自己用苹果手机 + 华为鸿蒙手机，鸿蒙那台的系统版本还没确认。
