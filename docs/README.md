## 三十秒现状（2026-11-28）

```
源头(33 个源) --30s--> 去重打分分级 --L2/L3 先推--> Bark 通知
                            |
                            +--每 2 分钟提交--> data/*.json --30s 轮询--> 手机看板
```

- 看板：https://fcshen.github.io/news-radar/
- 通知延迟 20~30 秒，看板延迟约 1 分钟
- 保活：续链（每次运行开局派发下一次）+ `*/20` 兜底 cron + 独立 watchdog
- 已不需要任何第三方账号、外部定时器或 GitHub 令牌

## 两份副本的关系

本机归档目录 `D:\news-radar-归档\` 是主副本（含旧备份 zip），这里 `docs/` 是镜像，方便在 GitHub 上直接看。

改完本机那份后同步过来：

```bash
bash tools/sync_docs.sh
```

脚本只同步三份文档（`README.md` 是各位置自己的索引，不参与同步）。
